How to create relationships between items

You can add items to your timeline using any of the following methods:

Add relationships using Relationship View

  1. Change your view into Relationship View
  2. Click on "Choose Columns", and select the entities you want to show along the top of the view
  3. The intersection between each row and column will show relationships that exist between those items
  4. Click on an Intersection to see a dropdown of the available relationship types
  5. Click on a relationship type to toggle that option on or off

Add relationships in the Inspector

  1. Select the event or other item to which you want to add relationships
  2. If the Inspector is not visible, show it by clicking on the Toolbar icon (Desktop-only)
  3. Change the inspector tab to the Relationship tab (person icon)
  4. Existing relationships will be listed
  5. Click on the + next to an existing relationship type, or click on "Add Relationships" to choose from more relationship types
  6. Select the name of the item you want to add the relationship to

Add relationship in Mindmap View

To create relationships between two existing nodes in Mindmap View:

  1. Hover your mouse over one of the items until the Connector icon appears
  2. Click and drag from the connector icon to the other item you want to create a relationship to (a line will be shown following your mouse, and the item will highlight when you hover over it)
  3. Release the mouse, and select the type of relationship you wish to create
  4. You can repeat this process to remove an existing relationship also

Note: to add existing items to a Mindmap, drag them in from any other view.

Add or drag items into a filtered view

When you create a new item or drag an existing item into a filtered view, it will automatically assign relationships to match the current filter.

  1. Setup a local filter for the view by clicking on the Filter icon next to an item in an Entity panel
  2. Drag items from another view and drop them into the current view
  3. A relationship will be created between the dropped item and any items used in the filter (the default relationship type between those item types will be used)
  4. When creating an item directly inside that view, relationships will be created for the new item also

Note: The Filter Panel (global or focused view) can also be used to create automatic relationships, as well as other properties that can be automatically assigned.
